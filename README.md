# СметаПро

iPhone‑приложение для тех, кто строит и ремонтирует: сметы по документам и по параметрам, 3D‑обмер дома и
комнат лидаром, расчёт материалов, дизайн интерьера и фасада с ИИ, чертежи, AR‑рулетка, калькуляторы.
Языки интерфейса: русский, English, Español, 简体中文 (по настройке iPhone). Единицы: метры или футы.

Запуск: откройте `Markaryan.xcodeproj` в Xcode, выберите iPhone и нажмите **Cmd + R**.
Рядом с проектом должен лежать `Markaryan/AIServer.plist` (адрес сервера и токен приложения; в git его нет).

## Что умеет

**Сметы**
- **Смета по документам** — АР, КР, ТЗ, Excel или список работ: объёмы, материалы с нормами расхода, цены города со ссылками; КП в PDF.
- **Смета дома и металлоконструкций** по параметрам — недельный прайс города, без ИИ, мгновенно.
- **14 калькуляторов** материалов: бетон, плитка, кладка, штукатурка, стяжка, гипсокартон, кровля, утеплитель, забор…

**3D‑обмер дома** (снаружи)
- Обход дома с iPhone: кольцо покрытия, мини‑карта обхода, расстояние до стены, голосовые подсказки на 4 языках, «Сторона недоступна».
- Обработка на сервере (`gpu-worker/`, Open3D): стены и контур дома (в т.ч. Г‑образный), карниз, конёк, уклон, свесы, двускатная/вальмовая крыша, окна и двери по фото.
  Точность на синтетических тестах — 1–2 см; у каждого размера метка «измерено / по фото / предположение».
- Площади для сметы: кровля со свесами, фасад без проёмов, водосток, периметр. Участок по кадастру (НСПД) и проверка отступов по СП.

**Дизайн комнаты**
- Скан комнат лидаром (Apple RoomPlan), квартира целиком в общих координатах, мини‑карта квартиры, тип комнаты, «Переснять», голосовые подсказки.
- **Расчёт материалов по скану**: плитка раскладкой (пол и стены до нужной высоты), клей по формату, затирка, СВП, гидроизоляция санузла,
  штукатурка по маякам, стяжка, наливной пол, шпаклёвка и краска, ламинат, плинтус — с упаковками, нормами и ценами города.
- Дизайн ИИ по планировке, расстановка мебели с проверкой проходов, фотореалистичная презентация, чертежи А3 по ГОСТ и DXF.
- Дизайн по фото, визуализация фасада и участка, свои материалы.

**Ещё**: AR‑рулетка, счёт арматуры и труб по фото, ИИ‑помощник на каждом экране, проект объекта (бюджет, этапы, фото скрытых работ), оплата кредитами.

## Устройство
| Часть | Где | Что |
|---|---|---|
| Приложение | `Markaryan/` | SwiftUI, iOS 17; ключей ИИ в приложении нет |
| Сервер ИИ | `server/` | Node.js: OpenRouter, сметы, цены, оплата, приём сканов, очередь обработки |
| Обработчик сканов | `gpu-worker/` | Python + Open3D: TSDF‑сетка, плоскости, дом; запускается на сервере (позже — на арендуемом GPU) |
| Локализация | `l10n/`, `Markaryan/Localizable.xcstrings` | выгрузка строк Xcode (GitHub Actions) → перевод со словарём и вычиткой → каталог |
| Документы | `docs/` | спецификация 3D‑обмера (`docs/house-exterior/SPEC-0-1.md`), тексты App Store на 4 языках |

## Проверки (GitHub Actions)
- `ios.yml` — тесты (`sh Tests/run.sh`: калькуляторы, планы, дизайн, материалы, участок) и сборка приложения; ошибки — аннотациями.
- `house-worker.yml` — обработчик сканов на синтетических домах известных размеров.
- `l10n-export.yml` — выгрузка строк интерфейса в `l10n/en.xliff`; перевод: `python3 -I l10n/translate.py en es zh-Hans` (нужен `OPENROUTER_API_KEY`).
- Сервер: `cd server && npm test`.

### Сборка в TestFlight
Workflow «TestFlight — сборка и загрузка» собирает Release‑архив и загружает в App Store Connect. Секреты репозитория:
`ASC_KEY_ID`, `ASC_ISSUER_ID`, `ASC_KEY_P8` (командный ключ App Store Connect API с ролью Admin) и `AI_SERVER_PLIST`
(настоящий `Markaryan/AIServer.plist`). Запуск: Actions → «TestFlight — сборка и загрузка» → Run workflow.
